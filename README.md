# The Living Heritage Route

Interactive map of Mimar Sinan's works along the imperial road (Sol Kol) between İstanbul and Edirne.
A research project of ARCHITHE, the Architectural History and Theory Laboratory, Özyeğin University.

Project page: https://labs.ozyegin.edu.tr/archithe/projects/living-heritage-route/

To update the map, replace `index.html` with the new version.
Photos go in a `photos` folder next to `index.html`.
